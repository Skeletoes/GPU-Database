# GPU-Database

A Python and SQLite-based application for managing and searching a database of graphics cards.

## Features

- **User Authentication:** Login, create accounts, or use as guest.
- **GPU Lookup:** Search GPUs by brand, model, speed, architecture, memory, and more.
- **Add/Edit/Delete GPUs:** Easily manage GPU entries in the database.
- **Recent Searches:** Tracks and displays recent user searches.
- **Tabulated Output:** Results are displayed in a readable table format.

## Files

- `Brenton Database Python.py`: Main application source code.
- `Brenton Main Database.db`: SQLite database file.
- `graphics_cards.csv`: CSV data for graphics cards.
- `users.csv`: CSV data for users.
- `README.md`: Project documentation.

## Getting Started

1. Install Python and required packages (`tabulate`).
2. Ensure `Brenton Main Database.db` exists and is populated.
3. Run `Brenton Database Python.py` to start the application.

## Usage

- Follow prompts to sign in, search, add, edit, or delete GPUs.
- Use 'quit' at any prompt to exit or go back.
